Tema elegido: Simulador interactivo de ahorro (Días/Meses) con multiplicador de Fibonacci

Estudiante: Salinas Ramos Diego

1. Contexto del Problema (Introducción)

Esta aplicación sirve como una herramienta práctica y didáctica para que las personas visualicen y proyecten en tiempo real cuánto dinero pueden ahorrar. Muchos planes tradicionales fallan porque exigen cuotas fijas que se vuelven difíciles de mantener. Este simulador propone un sistema dinámico basado en la famosa serie matemática de Fibonacci.

El propósito principal es ofrecer flexibilidad al ahorrador. Al permitirle elegir el tiempo y la cantidad inicial, el usuario puede experimentar y estructurar un hábito financiero que se adapte perfectamente a sus capacidades económicas, observando cómo pequeños depósitos se convierten en capitales significativos.

2. Explicación del Algoritmo y Funcionamiento del Plan

El programa calcula de manera automatizada la secuencia de Fibonacci mediante un bucle iterativo for controlado por el tiempo que introduzca el usuario. Dentro de este ciclo se procesa la fórmula matemática tradicional c = a + b para definir el valor de cada periodo.

¿Para qué sirve la cantidad inicial base y por qué la pusimos? La serie de Fibonacci pura siempre comienza con los valores mínimos de 1 y 1. Si dejáramos el simulador así, el usuario estaría obligado a ahorrar montos fijos muy pequeños (Bs. 1, Bs. 1, Bs. 2, Bs. 3...). Para solucionar esto e introducir una utilidad financiera real, incluimos el campo "Cantidad inicial base". Esta variable funciona como un factor de escala multiplicador: toma el valor puro de Fibonacci de ese mes/día y lo multiplica por el dinero base que el usuario decida ingresar. Esto sirve para adaptar el plan al presupuesto de cualquier persona, permitiendo simular planes más altos de forma proporcional.

Diferencia entre Depósito Correspondiente y Saldo Acumulado: Es fundamental comprender que el programa maneja estos dos conceptos financieros de manera independiente dentro del bucle:

  • Depósito Correspondiente: Es la cantidad exacta de dinero en bolivianos (Bs.) que el ahorrador debe meter a su alcancía exclusivamente en ese día o mes específico. Este valor sigue la regla de Fibonacci multiplicada por la base (por ejemplo, en un plan con base de 5 Bs., los depósitos sucesivos serán de 5, 5, 10, 15, 25 Bs., donde cada depósito se calcula sumando las dos cuotas anteriores).
  • Saldo Acumulado: Representa el pozo total o fondo acumulado que ya se encuentra guardado dentro de la alcancía. El algoritmo lo calcula sumando dinámicamente el depósito del periodo actual con el dinero total que ya se había recaudado en todos los pasos anteriores.

¿Por qué incluimos la opción de elegir Días o Meses? Debido a que la serie de Fibonacci crece de forma exponencial (sumamente rápido), si se calcula un plan diario por muchos meses, el depósito requerido se dispararía a montos inalcanzables. Al añadir esta separación, permitimos que las personas que buscan metas a corto plazo vean exactamente cuánto pueden reunir día por día en periodos pequeños (de 1 a 30 días). Para metas de mediano o largo plazo, la persona selecciona el modo "Meses", manteniendo las cuotas dentro de montos realistas y accesibles para la economía de un hogar.
